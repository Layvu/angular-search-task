# Angular User List App

Веб-приложение для отображения и фильтрации списка пользователей

## Функционал

- Отображение списка пользователей с полями:
  - `id`
  - `name`
  - `email`
  - `active`
- Поиск по имени
- Фильтрация по статусу:
  - все
  - активные
  - неактивные
- При клике на пользователя отображается его email в отдельном блоке

## Технологии

- **Angular**
- **RxJS**
- **Reactive Forms**
- **LESS**

## Данные

- По умолчанию загружаются моки из `mock-users.ts`
- При наличии API запрос идёт на `/api/users`, при ошибке используется fallback на моковые данные

## Запуск проекта

```bash
npm install
npm start
```
